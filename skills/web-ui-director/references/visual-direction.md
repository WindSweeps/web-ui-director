# Visual direction

Describe the intended direction in terms of the task, hierarchy, typography, density, color, and interaction. When a reference is supplied, identify which qualities serve the current interface. Use title, placement, weight, contrast, and whitespace to form a hierarchy before adding borders, shadows, or gradients.

Define canvas, surface, elevated surface, primary and secondary text, separator, accent, focus, and status colors. For an identity-led palette such as Berkeley's, use a dominant identity color, a companion, a neutral base, and secondary color families with clear semantic roles. Check real foreground and background combinations in normal and interactive states.

When the brief requests an Apple-inspired direction, consider related corner radii, consistent elevation, restrained contrast, and clear separation between content and controls. Use solid surfaces for primary content. Use translucency for overlays or navigation when seeing the underlying content helps, and provide a more opaque surface for reduced transparency or noisy backgrounds.

Use motion to show state change, direction, or spatial continuity. Keep frequent transitions brief, support interruption, and preserve essential feedback in reduced-motion mode.
