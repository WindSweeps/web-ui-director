# Implementation and review

Inspect the actual route, data states, styles, assets, and project checks. Record assumptions only when they affect the result. Place controls near the content they affect and make headings specific to the task.

At the delivered entry point, verify:

- Main task, reading order, shared edges, spans, and wrapping across wide, intermediate, and narrow layouts.
- Discrete font-size changes across breakpoints and matching resolved sizes for each role, including controls and charts.
- Long labels, mixed scripts, text enlargement up to 200%, and retention of content and functionality. Inspect horizontal overflow, clipping, sticky regions, and overlapping layers.
- Keyboard operation, visible focus, accessible names, contrast, target areas, and reduced-motion settings. Verify state feedback using text, shape, or icons as appropriate.
- Loading, empty, error, success, disabled, and selected states relevant to the flow. Check runtime errors, font loading, and broken assets.

Fix observed issues and repeat the relevant checks. Record the actual dimensions, states, or interactions covered when those details affect confidence. If runtime access is limited, identify the checks that remain unverified.
